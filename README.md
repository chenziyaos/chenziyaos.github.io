# chenziyaos.github.io

Project showcase served at https://chenziyaos.github.io/ (plain static HTML, no build step on GitHub Pages).

- `index.html` is generated by `tools/build.py` from `tools/index.tpl.html` plus the chapter headings in each series repo (`zero-to-*/book/`, `nginx-devops/ops|dev/`):

  ```bash
  # clone zero-to-llm, zero-to-vllm, zero-to-sglang, zero-to-llama, zero-to-gpu and nginx-devops side by side under <dir>
  python3 tools/build.py <dir>
  ```

- Chapter links open each repo's online edition at `https://chenziyaos.github.io/<repo>/`, built with MkDocs by that repo's own Pages workflow; this repo only links to it.
- The old Hexo blog (2016–2017) lives on the `archive/hexo-blog-2017` branch.
- `/weft/` and `/<series repo>/` are served by those repos' own Pages sites; do not add directories with those names here.
