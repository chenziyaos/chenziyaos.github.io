# chenziyaos.github.io

Project showcase served at https://chenziyaos.github.io/ (plain static HTML, no build step on GitHub Pages).

- `index.html` is generated by `tools/build.py` from `tools/index.tpl.html` plus the chapter headings in each `zero-to-*/book/`:

  ```bash
  # clone zero-to-vllm, zero-to-sglang, zero-to-llama, zero-to-gpu side by side under <dir>
  python3 tools/build.py <dir>
  ```

- The old Hexo blog (2016–2017) lives on the `archive/hexo-blog-2017` branch.
- `/weft/` is served by the separate `weft` repo's Pages site; do not add a `weft/` directory here.
